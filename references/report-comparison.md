## 第二份：继续被标记的代表区域

第二份报告共3个“部分”，AI特征值分别为34.8%、29.5%、29.8%。报告第2、9、17页片段指标列表合计9个显著标记片段。对应选段汇编中涉及的典型位置：

1. 中文摘要开头/（1）、（4）—（5）及英文摘要若干结论：报告第2—4页。**启发**：将任务列表从完全同构的“研究→方法→结果→意义”改为贴合实际内容的叙述，而不是逐段套统一句型。
2. 绪论研究背景与文献综述（代表性显著片段2014字符，见第2页片段列表以及第6页1.2.2的相关文本）。**启发**：纯语言重组后仍可能高标，抽象总结和同质过渡需要具体依据支持，但不得虚构文献。
3. 充填工艺及关键技术问题（代表片段1097字符，第9—10页）。**启发**：机械“（1）技术问题 / （2）技术问题 + 每段3句概括”可能仍同质；保留必要编号，调整段内句法，不改变技术措施。
4. 相似理论、相似准则（代表片段968字符，第10—11页）。**启发**：固有理论术语和公式不因标红而可以重写错；以准确说明和应用边界为先。
5. 月生产能力三阶段结果分析（代表片段968字符，第15—16页）。**启发**：大量统计数值的段落也会标记，不能认为“增加数字”就解决写作问题；注意数据统计基准和各阶段的逻辑对应。
6. 未来展望（代表片段621字符，第18—19页）。**启发**：模板化“首先……其次……未来可……”无需机械重复，但真实研究不足与后续方向不能擅改。

## 从对照中不能得到的结论

- 不能断言知网的隐藏规则是“句长20—35字”“术语放在主语位置”“不用因此”等。
- 不能说某种句式必然导致标红或一种替换必然降低分数。
- 不能把GitHub个案自测幅度视为普适成功率。
- 不能因为数值密集章节整体较低就推定数值越多越安全。
- 不能无视重复率和AIGC检测是不同指标。

## 实施反思：旧做法与改进

| 旧做法 | 问题 | 现在的方法 |
|---|---|---|
| 将“显著”统一换成“明显” | 改动表层词语，论证结构仍可能同构；还可能改变强度 | 保留合适术语，改真实的重复句法 |
| 全段切成多个短句 | 逻辑变碎，依然模板化 | 依据主谓关系和因果层次拆并 |
| 不分章节统一换模板 | 摘要、理论、图表、展望的写作目的不同 | 先判断段落功能，再局部重构 |
| 为了“自然”补充原因/建议 | 新增未经用户提供的事实或因果 | 仅重组原有证据，不加新意思 |
| 看到标红就大幅改动术语 | 损害技术准确与引用有效性 | 优先最小必要改写，锁定数据公式引用 |
| 把两份报告当同样的前后全文 | 分母与文本范围不同 | 只作定性段落模式对照，不报告伪造降幅 |
